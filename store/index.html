navSounds add-on for NVDA

Sound store

This is the sound store for the navSounds add-on. Every pack below is a zip of wav files that the add-on imports from inside NVDA, so you can change the sounds without reinstalling the add-on. Navigation packs cover controls and states, typing packs cover keyboard echoes in text fields.

All sounds are plain wav files. Nothing here runs code: an imported pack is only ever a list of audio files.

How to install a pack

  1. Download the .zip of the pack you want from the list below.
  2. Open the NVDA settings dialog and go to the navSounds panel.
  3. Press import sound theme... and choose the zip you downloaded.
  4. Say which sounds it contains, then pick the new theme from select sound or select typing sound and apply the settings.

You can also press open theme store in the add-on panel to come back to this page from NVDA.

Submit a pack

Made your own sounds? Open a new issue with the sound theme submission form, describe the pack, and attach the zip. If you attach a short audio sample as well it becomes the preview on this page, so people can hear the pack before they download it.

Open the submission form

You can be credited under any name you like, not only your GitHub account name. Please test the pack on your own machine first, with the add-on and with NVDA, and tell us which versions you used.
